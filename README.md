# ipl_data_analysis

# 🏏 IPL Data Analysis Dashboard Project

> "Cricket is not just a game, it’s a data science challenge waiting to be solved."

Welcome to my **IPL Data Analysis** project! This project explores in-depth match statistics and player performances from the Indian Premier League using Python for analysis and Power BI for rich interactive visualisations.

## 🔍 Project Overview

This project aims to provide analytical insights into IPL matches by processing and visualising player and match data. We used Python for data cleaning and exploration, and Power BI to design a user-friendly dashboard highlighting player and team performance trends.

### ✅ Objectives

- Clean and process IPL match delivery-level data.
- Perform Exploratory Data Analysis (EDA) on runs, wickets, player stats, and match outcomes.
- Build a dynamic, interactive Power BI dashboard for insights delivery.

---

## 🛠️ Tech Stack

| Tool/Language | Purpose |
|---------------|---------|
| Python        | Data Preprocessing & EDA |
| Pandas, NumPy | Data manipulation |
| Matplotlib, Seaborn | Visual Analytics |
| Power BI      | Dashboard Creation & Reporting |

---

## 📂 Dataset Details

Dataset used: `deliveries.csv`  
Columns included:
- `match_id`, `inning`, `batting_team`, `bowling_team`, `over`, `ball`
- `batter`, `bowler`, `non_striker`, `batsman_runs`, `extra_runs`
- `total_runs`, `is_wicket`, `player_dismissed`, `dismissal_kind`

---

## 📊 Dashboard Highlights

- **Top Batsmen** based on total runs scored.
- **Top Bowlers** based on total wickets taken.
- **Team-wise Analysis** (Runs per match, Matches played).
- **Stadium Performance**: Most matches played by location.
- Filters on **teams**, **seasons**, **players**, and **innings** for dynamic slicing.
